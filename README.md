# Rohan Karthick — Ultra-Premium Portfolio Website

An award-caliber personal portfolio website engineered with world-class creative development standards.

## 🚀 Key Highlights & Tech Architecture

- **Aesthetic**: Dark Cinematic Editorial (`#050507`), with Deep Crimson Glow & Cybernetic Accents.
- **Typography**: Syne, Space Grotesk, JetBrains Mono.
- **Motion & Scroll**: Lenis Smooth Scrolling + GSAP ScrollTrigger velocity distortion and pinned horizontal track.
- **3D & WebGL**: Three.js + React Three Fiber + Drei custom morphing crystalline geometries & ambient particle fields.
- **Audio Synthesis**: Pure Web Audio API procedural sound engine with click impulses, hover harmonics, and mute toggle.
- **Adaptive Cursor**: Spring-interpolated cursor with context-aware morphing (`EXPLORE`, `VIEW`, `DRAG`, `AUDIO`).
- **Interactive Ecosystem**: Connected technology neural network with live code inspection.
- **7 Detailed Case Studies**: AcousticPulse, Internet Speed Analyzer, Smart Study Planner, SkillSwap, Student Performance Prediction, Smart Waste Management, and Edge AI / TinyML.
- **Experimental WebGL Lab**: Real-time 3D geometry & shader playground with interactive parameters (Aura palette, Wireframe, Velocity).
- **Editorial Visual Gallery**: Dark-mode masonry showcase with EXIF camera data and keyboard-driven lightbox.
- **Verified Milestones**: Hackathons, open-source distinctions, and academic achievements.
- **Contact Matrix**: Instant one-click email copy to clipboard with confetti feedback and interactive inquiry form.

## 🛠️ Development & Deployment

To run locally in development mode:
```bash
npm run dev
```

To build production bundle:
```bash
npm run build
```

To preview the production build:
```bash
npm run preview
```
